# 🧠 Нервная система — викторина по биологии

Сайт-викторина для 9 класса по учебнику О. Л. Борисова и др. «Биология» (2025), глава 2 «Нервная система» (§5–10).

- **Тест** — вопросы с вариантами ответа и пояснениями; можно выбрать параграф.
- **Соедини линиями** — протяни линию от понятия к его описанию (мышью, пальцем или двумя нажатиями).

Открывается без установки: достаточно файла `index.html`.

## Свои вопросы

Все вопросы лежат в `questions.js` — формат описан в начале файла.
